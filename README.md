# 📰 Real-Time Fake News Detection System

> 🎓 Final Year Design Project, Department of CSE, Daffodil International University

> 🚧 **Work in progress.** Code, results and documentation will be added when the project is complete.

## 📌 Overview

A system that detects fake news in real time using **Natural Language Processing (NLP)** and **Machine Learning**. Given a news article or headline, it classifies the content as **real** or **fake**.

## 🛠️ Planned stack

- **Python**
- **NLTK** for text preprocessing
- **Scikit-learn** for machine learning models
- **Pandas** and **NumPy** for data handling
